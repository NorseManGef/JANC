# <p style="text-align: center;">Just Another Nix Config!</p>

Just Another Nix Config, or JANC, is my personal nix project. It is based on nix flakes, allowing it to be easily reproducible, stable, and use modern packages.

### Features

- Multiple configurations, with AMD and NVidia GPU support, for both laptop and desktop systems.

- Hyprland configurations with waybar

- Custom firefox configuration using Adrian Karlen's Textfox

- Easy color scheme control with stylix

- Neovim configurations
